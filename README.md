# PacketForge —— 浏览器端一体化 Web 安全测试工具箱

PacketForge 是一款基于 Chrome Manifest V3 的 DevTools 扩展，定位是"长在开发者工具里的轻量级 Burp Suite"，纯前端实现、无后端、数据不出本机。

## 功能

### 1. 网络捕获
- 通过 `chrome.debugger` 接管页面网络栈，完整记录全部 HTTP/HTTPS 请求
- 捕获请求头、请求体与响应体（单条响应最大 500KB），最多缓存 2000 条
- 支持按方法、状态码、内容类型、URL 关键字组合过滤
- 批量勾选导出 CSV（`result_时间戳.csv`，UTF-8 BOM，Excel 直接打开不乱码）
- 单条请求右键导出 cURL 脚本，便于归档与复现

### 2. 请求重放器
- 任意捕获记录一键载入编辑器，自由改写方法、URL、请求头、请求体
- 原样重发，快速验证越权、参数篡改、鉴权绕过
- 重放历史自动留存，多次改包结果可对比

### 3. Intruder 爆破模块
- 四种攻击模式：狙击手（Sniper）、攻城锤（Battering ram）、草叉（Pitchfork）、集束炸弹（Cluster bomb）
- 多变量同时标记，支持自定义 payload 字典
- 内置编码与哈希变换（Base64/URL/MD5/SHA 等）
- Grep 匹配规则 + 响应差异分析，快速定位异常响应
- 并发数与请求速率可调；结果可导出
- 适用场景：弱口令枚举、参数 Fuzz、IDOR 遍历

### 4. 竞态测试
- 将任意请求构造为多个完全同步的并发副本
- 用于验证限时优惠、重复提现、签到刷量等竞态条件漏洞
- 弥补顺序重放无法触发的时序问题

### 5. 解码器
- URL、Base64、HTML 实体等常见编码一键编解码
- 支持嵌套解码，应对多层包裹的参数还原

### 6. 设计特点
- 纯前端、无后端服务，数据全部留存本机
- 全中文界面，上手成本低
- 附带侧边栏（Sidepanel）捕获视图，边浏览边观察流量

## 安装

本扩展未上架 Chrome 应用商店，请以开发者模式加载：

1. 下载本仓库（`Code → Download ZIP`），解压到本地
2. 打开 Chrome，地址栏进入 `chrome://extensions`
3. 打开右上角"开发者模式"开关
4. 点击"加载已解压的扩展程序"，选择解压后的文件夹
5. 在任意网页按 `F12` 打开 DevTools，顶部会出现 **PacketForge** 标签
